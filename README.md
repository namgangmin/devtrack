
# DevTrack

개발 프로젝트와 작업 진행 상황을 관리하는 웹 애플리케이션입니다.

## 기술 스택

- Backend: Java, Spring Boot
- Frontend: React
- Database: PostgreSQL
- Version Control: Git, GitHub

## 개발 목표

Spring Boot와 React를 활용해 풀스택 개발 역량을 복습하고, 실제 작동하는 웹서비스를 구현합니다.

- [ ] 프로젝트 관리 기능 구현
